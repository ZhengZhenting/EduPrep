# 用户旅程图 (User Journey Map)

> **状态**: Draft (P6 用户研究 · 轻量版)
> **更新**: 2026-06-23
> **关联**: [personas.md](./personas.md) · [pain-points-to-features.md](./pain-points-to-features.md)

本图追踪一名国际学生（以 Persona 2「Wei」为主线）从**拿到一门课的德语讲义**到**通过期末考试**的完整旅程，标出每个阶段的行为、痛点、情绪，以及 EduPrep 的介入点。

---

## 旅程总览

```
①拿到讲义 → ②初次阅读 → ③消化提问 → ④跨材料整合 → ⑤考前复习 → ⑥应考
   预习         预习/学习      学习          学习(图谱)      复习          —
```

---

## 分阶段拆解

### ① 拿到讲义 PDF（学期初/每周）
- **行为**: 下载德语 PDF，扫一眼，不知从何入手
- **痛点**: 满屏德语术语，不知道这章讲什么、重点在哪
- **情绪**: 😟 畏难
- **EduPrep 介入**: **Preview** — 双语摘要 + 词汇表 + 结构图，5 分钟建立全局认知
- **阶段**: 预习

### ② 初次阅读
- **行为**: 逐段读，遇到术语反复查
- **痛点**: 查词打断阅读节奏；不确定理解是否正确
- **情绪**: 😐 吃力
- **EduPrep 介入**: Preview 的术语对照 +（未来）术语图谱节点
- **阶段**: 预习 → 学习

### ③ 消化与提问
- **行为**: 针对看不懂的点提问
- **痛点**: 普通搜索答案不贴合讲义；不确定答案是否有出处
- **情绪**: 🙂 渐入佳境
- **EduPrep 介入**: **Learn** — 混合 RAG 问答（锚定 PDF + 标注来源页）+（未来）Agent 引用核对防幻觉
- **阶段**: 学习

### ④ 跨材料整合（学期中后段）⭐ 当前最大缺口
- **行为**: 把第 3 周和第 9 周的相关概念联系起来
- **痛点**: **同一概念散落多份 PDF，串不起来；不知道概念的先后依赖** —— 现有逐 PDF 模式完全不支持
- **情绪**: 😣 混乱、焦虑
- **EduPrep 介入**: **课程级知识图谱**（P7）+ **GraphRAG 跨 PDF 检索 + 学习路径**（P8）
- **阶段**: 学习

### ⑤ 考前复习
- **行为**: 决定复习什么、做练习题
- **痛点**: **不知道自己哪里弱、该重点复习什么；学完又忘**
- **情绪**: 😰 时间紧、没底
- **EduPrep 介入**: **掌握度热力图 + 自适应出题 + FSRS 间隔重复**（P9）
- **阶段**: 复习

### ⑥ 应考
- **行为**: 参加考试
- **痛点**: 临场才发现某概念其实没掌握
- **情绪**: 😌 / 😖（取决于前面是否到位）
- **EduPrep 介入**: 前置阶段的掌握度追踪让"盲区"在考前就暴露并被补上
- **阶段**: —（闭环反馈回下一轮）

## 情绪曲线与机会点

```
情绪  😟 — 😐 — 🙂 — 😣 — 😰 ……（理想：被 EduPrep 抬平）
阶段  ①    ②    ③    ④    ⑤
                      ↑     ↑
                  最深低谷  次低谷
              (跨材料整合) (考前复习)
```

**两个最深的情绪低谷（④跨材料整合、⑤考前复习）正是现有产品的最大空白**，也正是 roadmap P7–P9 集中火力的地方。这从用户旅程角度印证了 roadmap 的优先级排序是合理的 —— 先补用户最痛、现有功能最缺的环节。

> 设计含义：EduPrep 的价值不在单点问答（③已基本满足），而在把零散文档整合成课程知识网络（④）并按学习规律安排复习（⑤）—— 这与[产品定位](../roadmap/eduprep_roadmap.html)完全一致。
