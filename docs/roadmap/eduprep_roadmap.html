EduPrep

Project Roadmap

为在德国的国际学生打造的 AI 学习系统 —— 从"能聊 PDF 的工具"演进为"懂你学到哪、知道你哪里弱、按学习规律安排你学什么"的个性化学习伙伴。 An AI learning system for international students in Germany — evolving from "a tool that chats with PDFs" into a personalised study companion that knows how far you've learned, where you're weak, and schedules what to study by the science of learning.

Start · 2026-06-20 P6 → P13 ≈ 8 months claude-opus-4-8 / sonnet-4-6

01产品定位Product Positioning

所有技术升级（多模态 / 知识图谱 / Agent / MCP）都是手段，主线永远是这个定位。 Every technical upgrade (multimodal / knowledge graph / Agent / MCP) is a means — the through-line is always this positioning.

EduPrep 不只是回答你的问题 —— 它为你的每门课构建知识图谱，追踪你对每个概念的掌握度，并按遗忘曲线安排你的预习、学习与复习。 EduPrep doesn't just answer your questions — it builds a knowledge graph for each of your courses, tracks your mastery of every concept, and schedules your Preview, Learn and Review along the forgetting curve.

差异化 = 个性化 (adaptive) · 知识图谱驱动 (knowledge-graph-driven) · 真正闭环的学习循环。区别于所有"逐个 PDF 聊天"的工具。 Differentiation = adaptive · knowledge-graph-driven · a truly closed learning loop. Distinct from every "chat-with-a-single-PDF" tool.

03架构关键判断：课程级 vs PDF 级Key Architecture Call: Course-level vs PDF-level

学习的真实单位是「一门课」而非「一份 PDF」。知识层与学习者模型上升到课程级；物理文档层保留 PDF 级。叠加一层，不推翻重做。 The real unit of learning is a course, not a PDF. The knowledge layer and learner model rise to course-level; the physical document layer stays PDF-level. A layer is added, nothing is torn down.

P7

Vision-LLM 多模态 IngestionVision-LLM Multimodal Ingestion

07-11 → 08-08 · 4w
多模态 · 解决纯文字盲区Multimodal · fixing the text-only blind spot ✅ 完成 · 负结果✅ Done · negative result

现有 PyPDFLoader 只抽文字层 —— 公式、图解、图片、表格大多丢失或损坏。德语讲义恰恰满是公式图解，这是检索质量的隐形天花板。 Today's PyPDFLoader only extracts the text layer — formulas, diagrams, images and tables are mostly lost or corrupted. German lecture slides are full of exactly these, making it a hidden ceiling on retrieval quality.

实测结论：Outcome: 整页视觉转写在讲义上净负 —— 转写让每页"读起来都像"（同质化），把精确相关页挤出 top-k（NCC/CGG 两份 deck 复现；CGG figure Recall 1.00→0.40）。真正的赢点是页眉/页脚剥离：NCC text Recall@5 0.25→0.42、overall 0.47→0.59，与纯文字讲义（Prompting 0.81）差距砍半。已默认关 vision、开页眉剥离、仅对无文字层扫描页保底。视觉价值迁往 P8 概念抽取 / P11 按需工具（`page_triage.py`/`vision_transcribe.py` 保留复用）。详见 multimodal-ingestion.md §8。 Full-page vision transcription is net-negative on lecture slides — it homogenizes pages (every page "reads alike"), crowding the exact page out of top-k (replicated on NCC & CGG; CGG figure Recall 1.00→0.40). The real win is header/footer stripping: NCC text Recall@5 0.25→0.42, overall 0.47→0.59, halving the gap to the prose deck (Prompting 0.81). Shipped: vision off by default, header-strip on, transcription only as a safety net for text-layer-less scans. Vision's value moves to P8 concept extraction / P11 on-demand tool (`page_triage.py`/`vision_transcribe.py` kept for reuse). See multimodal-ingestion.md §8.
功能 / 技术Features / Tech
  • 先做(零成本快速赢点)：幻灯片预处理 —— 切块前剥掉每页重复的导航页眉/页脚（实验发现这是 NCC 讲义 text recall 仅 0.25 的主因）Do first (zero-cost quick win): slide preprocessing — strip repeated nav headers/footers before chunking (found to be the main cause of NCC's 0.25 text recall)
  • 每页渲染成图片，用 Claude 视觉转写：公式→LaTeX、图解→文字描述、图片→内容描述、表格→结构化Render each page to an image, transcribe via Claude vision: formula→LaTeX, diagram→text description, image→content description, table→structured
  • 转写文本与原文一起切块入库（增强检索召回）Chunk transcribed text alongside the original (boosts retrieval recall)
  • 用 P6 的 content_modality 标签量化提升：公式/图解题的 Recall 增益Quantify the gain via P6's content_modality tags: recall lift on formula/figure questions
  • 评估 Nougat / Marker 作为公式解析备选Evaluate Nougat / Marker as formula-parsing alternatives
