# 对照实验:幻灯片讲义 vs 纯文字讲义的检索差异

> **状态**: 实验报告 (P6 评测的延伸)
> **日期**: 2026-06-27
> **方法**: [methodology.md](./methodology.md) · **基线**: [baseline.md](./baseline.md)(Prompt)· [baseline-machinelearning-simplecl.md](./baseline-machinelearning-simplecl.md)(NCC)

一句话:**我们以为多模态讲义的问题在"公式图表读不到",数据却显示主要问题在"幻灯片重复样板文字导致检索分不清页"。** 这是一次"实验 → 意外结果 → 洞察"的记录,直接修正了 P7 的优先级。

---

## 1. 实验设置

用同一套评测方法(检索 + LLM-judge),对比两份德语讲义:

| | **Prompt 讲义** | **NCC 讲义** |
|---|---|---|
| 文件 | LLM-Prompting.pdf | MachineLearning-SimpleClassifiers-NCC.pdf |
| 内容形态 | 纯文字(散文式) | **公式 + 散点图/几何图** 为主 |
| 题量 | 30(全 text) | 30(text / formula / figure 混合) |

NCC 是**对照组**:同样的 RAG 管线,只是内容形态变了。预期假设:**公式/图表类的 recall 会明显低于 text。**

---

## 2. 结果对照

| 指标 | Prompt(纯文字) | **NCC(公式图表)** | 变化 |
|---|---|---|---|
| **检索 Recall@5** | 0.81 | **0.407** | ⬇️ 几乎腰斩 |
| MRR | 0.515 | **0.205** | 首个相关结果从 ~rank2 退到 ~rank5 |
| Precision@5 | 0.19 | 0.081 | （指标天花板伪影,不深究） |
| **回答得分 Answer Score** | 0.85 | 0.772 | ⬇️ 小幅 |
| ├ 正确性 | 0.88 | 0.827 | |
| ├ 忠实度 | 0.98 | 0.933 | 仍很高 |
| ├ 引用准确 | 0.50 | 0.462 | 一贯短板 |
| └ 诚实性 | 1.0 | 1.0 | 仍满分 |

**头条结论成立**:公式/图表讲义的检索能力比纯文字讲义**崩了一半**(0.81 → 0.41)。多模态盲区被量化。

---

## 3. ⭐ 意外发现:按 modality 拆分推翻了假设

```
NCC 按 content_modality 拆分 (Recall):  text=0.250 · formula=0.556 · figure=0.500
```

**text(0.25)居然比 formula(0.56)、figure(0.50)还低** —— 与"公式图表更差"的直觉**相反**。

### 根因分析

1. **每页相同的导航页眉是主犯。**
   NCC 每张幻灯片顶部都印着同一行:
   > *Introduction · Prototypes · Nearest Centroid Classification · Linear Classification · Summary*
   这让所有 chunk 在向量空间里**长得极像**,检索器**分不清是哪一页**。对 **text 题伤害最大**——它们的答案往往是几个短词(如"NCC 的三个优点"),信号微弱,被重复页眉淹没。

2. **打乱的公式反而帮了检索。**
   `argmin`、`μ∆`、`w⊤x−β` 这类乱码符号是**罕见 token**,混合检索里的 **BM25(关键词侧)能精准命中**,把向量侧的差**救了回来**。所以 formula recall 没有想象中差。

3. **figure 题**(仅 6 条,样本小)部分靠 caption 关键词("NCC works / fails")命中。

> **结论**:这份讲义的主要失败模式**不是"读不懂公式",而是"幻灯片重复页眉 + 短文本低区分度,导致检索无法区分页面"**。

---

## 4. 第二个发现:Answer(0.77)远高于 Recall(0.41)

检索只对 41%,回答却有 77%。差距说明:**检索失败时,Claude 用自身的 ML 参数知识把答案补上了**(NCC、线性分类器是教科书内容)。

这是一个**测量混淆 (confound)**:
- 对**著名教材主题**,模型不太依赖检索也能答对 → 掩盖了检索的差。
- 换成**专有/冷门讲义**,这个代偿消失,Answer Score 也会跟着掉。

→ 洞察:**Answer Score 单独看会高估系统能力;必须和 Recall 一起看。Recall 才是检索层的真实体检。**

---

## 5. 对 P7(多模态 ingestion)的启示

数据**修正了 P7 的优先级**:

| 原计划 | 数据修正后 |
|---|---|
| 主投入:Vision-LLM 转写公式/图表 | 仍要做,但**不是最便宜的赢点** |
| —— | **新增更高性价比的快速赢点:幻灯片预处理 —— 切块前剥掉重复页眉、合并稀疏短文本** |

理由:把 text recall 从 0.25 拉起来,**剥页眉**可能比上 Vision-LLM 更快见效、成本几乎为零。Vision-LLM 留给真正需要"看图"的 formula/figure 内容。

> 已据此更新 [multimodal-ingestion.md](../architecture/multimodal-ingestion.md)(新增"幻灯片预处理"快速赢点)和 roadmap P7。

---

## 6. 局限

- **样本小**:每个 modality 层 6–15 题,层内均值噪声大,只看大方向。
- **figure 题靠人工**:NCC 的图表题答案由人工对照图核对(评测环境无法渲染 PDF 视觉)。
- **judge 未人工校准**:结果含 LLM-judge 已知偏差(methodology §5.5)。
- 单一对照(2 份 PDF),不代表所有学科分布。

---

## 7. 一句话总结

> **这次对照的价值不在"证实了多模态更难",而在"用数据推翻了我们对原因的假设"** —— 真正的瓶颈是幻灯片样板文字,而非公式本身。没有这次实验,P7 可能把钱投错地方。这就是"先建评测、用数据驱动决策"的回报。
