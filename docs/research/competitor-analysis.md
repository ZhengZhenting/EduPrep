> **关联**: [pain-points-to-features.md](./pain-points-to-features.md) · [personas.md](./personas.md)

本文对比市面上学生可能用来替代 EduPrep 的工具，定位 EduPrep 的差异化空间。

---

## 对比维度说明

- **文档问答 (Doc Q&A)**: 能否就上传的资料做检索增强问答
- **跨文档知识图谱**: 是否把多份材料整合成概念网络（含先修关系）
- **掌握度追踪**: 是否建模"学习者对每个概念掌握到什么程度"
- **间隔重复**: 是否按遗忘曲线安排复习
- **自适应出题**: 出题是否随用户薄弱点/水平调整
- **双语/德语场景**: 是否针对德语学习 + 母语对照优化

## 逐个点评

**Google NotebookLM** — 最强的文档问答与摘要，体验好。但它是**无状态的**：不建模学习者、不追踪掌握度、不安排复习，且按"笔记本/来源"组织而非"课程知识网络"。EduPrep 的差异在于**学习者模型 + 学习闭环**。

**Notion AI** — 通用知识管理 + AI 辅助，强在整理，弱在针对学习场景的检索深度，无任何学习科学能力。

**ChatPDF 及同类** — 典型"逐个 PDF 聊天"工具，与 EduPrep 现状最接近，但**止步于单文档问答**，正是 EduPrep 要超越的形态。

**Anki** — 间隔重复的标杆（SM-2），但完全手动：用户要自己制卡、自己定义概念，没有文档理解、没有知识图谱、没有自动出题。EduPrep 用 FSRS + 自动概念抽取把这套能力**自动化并接入课程内容**。

**传统 RAG 模板项目** — 用 LangChain 一周能搭出来的形态，无差异化 —— 这恰是 EduPrep 需要主动拉开距离的对象。

## 差异化定位结论

市面工具基本落在两个孤立的象限：

```
        文档理解强
            │
 NotebookLM │ EduPrep
 ChatPDF    │ (目标态)
 ───────────┼───────────  学习科学强 →
            │
 传统RAG    │ Anki
            │
        文档理解弱
```

- **左上（文档理解强 / 学习科学弱）**: NotebookLM、ChatPDF —— 会读资料，但不管你学得怎样。
- **右下（学习科学强 / 文档理解弱）**: Anki —— 会安排复习，但不懂你的资料、全靠手动。
- **右上象限基本空缺** —— **同时具备"深度文档理解（知识图谱/GraphRAG）"和"学习科学（知识追踪/FSRS/自适应）"，并针对德语国际学生场景优化**，正是 EduPrep 的目标占位。

> EduPrep 不与 NotebookLM 比"谁问答更好"，而是占据一个**两类工具都没覆盖的交叉象限**：把"懂资料"和"懂学习"合二为一。这就是项目深度的产品层表达。
